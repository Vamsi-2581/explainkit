# Fonts

All fonts here are licensed under the SIL Open Font License 1.1 (see the `OFL-*.txt` files) and are
redistributed unmodified as WOFF2 (Latin subset) from the Fontsource packages.

| Family | Weights used | Source |
|---|---|---|
| Barlow Condensed | 600, 700, 800 | https://github.com/jpt/barlow |
| Barlow | 400, 500, 700 | https://github.com/jpt/barlow |
| JetBrains Mono | 400, 700 | https://github.com/JetBrains/JetBrainsMono |

The renderer loads every face and waits for it before drawing the first frame, so text never falls back to a system font.
